## ข้อ 21 — [Lect 08] — เลือกเมทริกระยะทาง

**โจทย์:** ขณะทำ K-Means ด้วยมือในข้อสอบ อาจารย์ให้คำนวณระยะทางด้วยสูตรใด และเพราะอะไร

**ตัวเลือก**
- ก) ใช้ระยะทางแบบ Euclidean $d(A,Y) = \sqrt{\sum (x_i - y_i)^2}$ เพราะเป็นระยะทางที่สั้นที่สุดระหว่างสองจุด
- ข) ใช้ระยะทางแบบ Manhattan $Distance(A,Y) = |x_1-y_1| + |x_2-y_2| + \dots + |x_n-y_n|$ เพราะเป็นการบวกล้วน ไม่มีรากที่สอง ตรวจสอบด้วยมือได้ง่าย
- ค) ใช้ระยะทางแบบ Chebyshev เพราะคำนวณเร็วที่สุดเมื่อมีมิติข้อมูลมาก
- ง) ใช้ระยะทางแบบ cosine เพราะวัดความคล้ายของทิศทางได้ดีกว่า

**เฉลย:** ข) ใช้ระยะทางแบบ Manhattan เพราะเป็นการบวกล้วน ไม่มีรากที่สอง ตรวจสอบด้วยมือได้ง่าย

**วิธีทำ**
1. สไลด์เขียนสูตรที่อาจารย์ใช้ด้วยมือไว้ชัดเจนว่า $Distance(A,Y) = |x_1-y_1| + |x_2-y_2| + \dots + |x_n-y_n|$ ซึ่งคือ **Manhattan distance** (อีกชื่อ City-block distance)
2. ตรวจว่าสูตรนี้เป็นกรณีพิเศษของ Minkowski: $d(X,Y) = \left(\sum_i |x_i-y_i|^p\right)^{1/p}$
   - $p = 1$ → Manhattan (บวกค่าสัมบูรณ์)
   - $p = 2$ → Euclidean $d(A,Y) = \sqrt{\sum (x_i-y_i)^2}$
3. เหตุผลที่เลือก Manhattan ในการทำด้วยมือ: พิกัดเป็นจำนวนเต็มสองมิติ การคำนวณเป็น "ลบแล้วบวก" เช่น $|2-5| + |10-8| = 3 + 2 = 5$ ได้คำตอบเป็นจำนวนเต็ม ตรวจสอบได้ด้วยตาและด้วยกระดาษ
4. ถ้าใช้ Euclidean จะได้ $\sqrt{3^2 + 2^2} = \sqrt{13}$ ซึ่งไม่ใช่จำนวนเต็ม และเมื่อเทียบหลายจุดบนกระดาษจะตรวจสอบยาก — นี่ไม่ได้แปลว่า Euclidean "แย่กว่า" แต่แปลว่ามันไม่ใช่มิเตอร์ที่ตรวจด้วยมือได้สะดวก
5. ข้อสรุปที่ต้องเขียน: ในการทำด้วยมือใช้ Manhattan; ส่วน WCSS / Inertia ในทางทฤษฎีใช้ Euclidean แบบยกกำลังสอง ห้ามสลับ

**ตัวเลือกหลอก:** ข้อ ก — นักเรียนมักเลือกเพราะจำว่า "ระยะทาง" ในวิชาคณิตศาสตร์ปกติหมายถึงระยะตรง และเชื่อว่าสไลด์ต้องใช้มาตรฐานนั้น แต่สไลด์ระบุชัดว่าเป็น Manhattan และให้เหตุผลของการทำด้วยมือเป็นเหตุผลในการเลือก

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 สไลด์สูตร Manhattan / Minkowski (สไลด์ย่อย Euclidean)

## ข้อ 22 — [Lect 08] — คำนวณระยะทาง (Manhattan)

**โจทย์:** จุดข้อมูล A1 มีพิกัด (2, 10) และจุดศูนย์กลาง C2 มีพิกัด (5, 8) จงคำนวณระยะทางแบบ Manhattan ระหว่าง A1 กับ C2 แล้วเลือกข้อความที่ถูกต้อง

**ตัวเลือก**
- ก) 5
- ข) 3
- ค) 2
- ง) 13

**เฉลย:** ก) 5

**วิธีทำ**
1. สูตร Manhattan สำหรับ 2 มิติ: $d(P, C) = |x_P - x_C| + |y_P - y_C|$
2. แทนค่ามิติที่ 1: $|x_{A1} - x_{C2}| = |2 - 5| = |-3| = 3$
3. แทนค่ามิติที่ 2: $|y_{A1} - y_{C2}| = |10 - 8| = |2| = 2$
4. รวม: $3 + 2 = 5$
5. ตรวจกับตารางรอบที่ 1: แถว A1 มีค่าในคอลัมน์ "ถึง C2" เป็น 5 → ตรงกัน
6. ข้อสังเกต: ถ้าเป็น Euclidean จะได้ $\sqrt{(-3)^2 + 2^2} = \sqrt{9 + 4} = \sqrt{13}$ ซึ่งไม่เท่ากับ 5 จึงยืนยันว่าต้องระบุชนิดของมิเตอร์เสมอ

**ตัวเลือกหลอก:** ข้อ ง — 13 มาจากการ "ยกกำลังสองก่อนแล้วบวก" แบบ $3^2 + 2^2 = 9 + 4 = 13$ ซึ่งเป็นวิธีคิดของ squared Euclidean (ที่ใช้ใน WCSS/Inertia) ไม่ใช่ Manhattan ที่อาจารย์ใช้ตั้งโต๊ะ นักเรียนมักลืมว่าโจทย์ระบุชัดว่า Manhattan

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 ตารางรอบที่ 1 (แถว A1, คอลัมน์ "ถึง C2") + สไลด์สูตร Manhattan

## ข้อ 23 — [Lect 08] — อ่านตารางระยะทางเพื่อเลือกกลุ่ม

**โจทย์:** ในตารางรอบที่ 1 จุด A2 มีพิกัด (2, 5) และคำนวณระยะทางได้ดังนี้ ถึง C1 = 5, ถึง C2 = 6, ถึง C3 = 4 จงระบุว่าจุด A2 ต้องถูกย้ายไปอยู่กลุ่มใด และเพราะอะไร

**ตัวเลือก**
- ก) ไปกลุ่ม C1 เพราะ C1 คือจุดศูนย์กลางกลุ่มแรกและมีค่าน้ำหนักพิเศษ
- ข) ไปกลุ่ม C3 เพราะ 4 เป็นระยะทางที่น้อยที่สุดเทียบกับ C1 (5) และ C2 (6)
- ค) ไปกลุ่ม C2 เพราะ C2 อยู่ "กลาง" ของข้อมูลมากที่สุด
- ง) ไปกลุ่มทั้งสามกลุ่มเท่ากัน เพราะระยะทางต่างกันไม่มาก

**เฉลย:** ข) ไปกลุ่ม C3 เพราะ 4 เป็นระยะทางที่น้อยที่สุดเทียบกับ C1 (5) และ C2 (6)

**วิธีทำ**
1. ขั้นที่ 2 ของอัลกอริทึมคือ "หาระยะทางจากแต่ละจุดข้อมูลไปยังจุดศูนย์กลาง แล้วย้ายไปอยู่กับจุดที่ใกล้ที่สุด" คำว่า "ใกล้ที่สุด" คือ **ระยะทางต่ำสุด**
2. แถวของ A2 มีค่า 3 ช่อง: $d(A2, C1) = 5$, $d(A2, C2) = 6$, $d(A2, C3) = 4$
3. หาค่าต่ำสุด: $\min(5, 6, 4) = 4$ จึงไปกลุ่ม C3
4. ตรวจย้อนด้วยการแทนค่าจริง:
   - ถึง C1(2,10): $|2-2| + |5-10| = 0 + 5 = 5$
   - ถึง C2(5,8): $|2-5| + |5-8| = 3 + 3 = 6$
   - ถึง C3(1,2): $|2-1| + |5-2| = 1 + 3 = 4$ ← น้อยที่สุด
5. ผลที่ได้: หลังจบรอบที่ 1 กลุ่ม C3 มีสมาชิก A2 และ A7

**ตัวเลือกหลอก:** ข้อ ค — นักเรียนมักเดาตาม "ความรู้สึกเชิงพื้นที่" ว่าจุดกลุ่มกลางต้องเป็นกลุ่มที่จุดข้อมูลส่วนใหญ่อยู่ แต่กลุ่ม C2 ที่ได้สมาชิกมากที่สุด (5 จุด) เป็นผลที่ "ได้มา" หลังคำนวณเสร็จ ไม่ใช่เกณฑ์ตัดสินก่อนคำนวณ — เกณฑ์เดียวที่ใช้คือระยะทางต่ำสุด

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 ตารางรอบที่ 1 (แถว A2) + ขั้นตอนที่ 2 ของอัลกอริทึม

## ข้อ 24 — [Lect 08] — คำนวณ centroid ใหม่ของกลุ่ม C2

**โจทย์:** หลังจบรอบที่ 1 กลุ่ม C2 มีสมาชิก 5 จุด คือ A3(8,4), A4(5,8), A5(7,5), A6(6,4), A8(4,9) จงคำนวณจุดศูนย์กลางใหม่ของกลุ่มนี้ แล้วเลือกคู่พิกัดที่ถูกต้อง

**ตัวเลือก**
- ก) (6, 6)
- ข) (5, 6)
- ค) (6, 5)
- ง) (30, 30)

**เฉลย:** ก) (6, 6)

**วิธีทำ**
1. ขั้นที่ 3 ของอัลกอริทึมคือ "คำนวณค่าเฉลี่ยของแต่ละกลุ่มให้เป็นจุดศูนย์กลางใหม่" — เป็น **ค่าเฉลี่ย (mean)** ไม่ใช่ค่ามัธยฐาน
2. มิติที่ 1 (พิกัด x): ผลรวม = $8 + 5 + 7 + 6 + 4 = 30$ แล้วหารด้วยจำนวนสมาชิก 5 → $30 / 5 = 6$
3. มิติที่ 2 (พิกัด y): ผลรวม = $4 + 8 + 5 + 4 + 9 = 30$ แล้วหารด้วย 5 → $30 / 5 = 6$
4. รวมสองมิติ: $C2_{ใหม่} = (6, 6)$
5. จุดที่ต้องระวัง: ต้องหารด้วย **จำนวนสมาชิกของกลุ่มนั้น** (ที่นี่คือ 5) ไม่ใช่หารด้วยจำนวนจุดทั้งหมด 8 ถ้าหารด้วย 8 จะได้ $(3.75, 3.75)$ ซึ่งไม่ใช่ศูนย์กลางของกลุ่ม C2

**ตัวเลือกหลอก:** ข้อ ง — (30, 30) คือ **ผลรวม** ที่ยังไม่ได้หาร ซึ่งเกิดจากนักเรียนที่คำนวณรวมถูกแต่ลืมหาร ระวังว่าเป็นกับดักที่พบบ่อยที่สุดในข้อนี้; อีกคู่ที่มักโผล่คือ สลับมิติ (5,6) หรือ (6,5) ซึ่งเกิดจากคิดผลรวบของมิติหนึ่งผิก

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 ตารางอัปเดต centroid รอบที่ 2 (แถว C2) + ขั้นตอนที่ 3

## ข้อ 25 — [Lect 08] — เหตุผลที่ C1 ไม่ขยับ

**โจทย์:** หลังจบรอบที่ 1 กลุ่ม C1 มีสมาชิกเพียงจุดเดียวคือ A1(2,10) จงอธิบายว่าเหตุใดจุดศูนย์กลางของกลุ่มนี้จึงยังคงเป็น (2, 10) ไม่เปลี่ยน

**ตัวเลือก**
- ก) เพราะขั้นตอนที่ 3 ของสไลด์ไม่ได้กล่าวถึงการอัปเดต centroid เลย
- ข) เพราะกลุ่มที่มีสมาชิก 1 จุด ค่าเฉลี่ยของกลุ่มจะเท่ากับค่าของจุดนั้นพอดี จึงเป็น (2/1, 10/1) = (2, 10)
- ค) เพราะจุด A1 อยู่ใกล้จุดศูนย์กลางเดิมมาก (ระยะ 0) จึงไม่ถูกย้ายไปกลุ่มอื่น
- ง) เพราะ K-Means กำหนดให้จุดศูนย์กลางแรกต้องคงที่เสมอเพื่อใช้เป็นจุดอ้างอิง

**เฉลย:** ข) เพราะกลุ่มที่มีสมาชิก 1 จุด ค่าเฉลี่ยของกลุ่มจะเท่ากับค่าของจุดนั้นพอดี จึงเป็น (2/1, 10/1) = (2, 10)

**วิธีทำ**
1. ขั้นตอนที่ 3 คือการคำนวณค่าเฉลี่ยของกลุ่ม: $C = \left(\frac{\sum x_i}{n}, \frac{\sum y_i}{n}\right)$
2. กลุ่ม C1 มีสมาชิก 1 จุด ($n = 1$) คือ A1(2, 10)
   - มิติที่ 1: $2 / 1 = 2$
   - มิติที่ 2: $10 / 1 = 10$
   - ผลลัพธ์: $(2, 10)$ ซึ่งเท่ากับจุดเริ่มต้นพอดี
3. ดังนั้นจุดศูนย์กลางของกลุ่มนี้ "ไม่ขยับ" — ไม่ใช่เพราะขั้นตอนถูกข้าม แต่เพราะค่าเฉลี่ยของจุดเดียวเท่ากับจุดนั้นเอง
4. ผลที่ได้หลังอัปเดตทั้งสามกลุ่ม: $C1(2, 10) \cdot C2(6, 6) \cdot C3(1.5, 3.5)$
   - ตรวจ C3: สมาชิก A2(2,5), A7(1,2) → $((2+1)/2, (5+2)/2) = (3/2, 7/2) = (1.5, 3.5)$
5. ข้อสังเกตที่ควรเขียนเพิ่มในกระดาษ: กลุ่ม C1 ในรอบนี้เป็น "กลุ่มว่างเชิงกรม" (degenerate cluster) เพราะมีสมาชิกจุดเดียว — เป็นผลมาจากจุดศูนย์กลางเริ่มต้น C1 ตรงกับ A1 พอดี ซึ่งสอดคล้องกับจุดอ่อนที่สไลด์ระบุว่า "มักหยุดที่ local optimum ค่าเริ่มต้นจึงสำคัญ"

**ตัวเลือกหลอก:** ข้อ ค — ฟังดูมีเหตุผล แต่เป็นการอธิบาย **ว่าทำไม A1 จึงยังอยู่ในกลุ่ม C1** (ระยะทาง 0 จึงใกล้ที่สุด) ไม่ใช่คำถามที่โจทย์ถาม โจทย์ถามว่า **ทำไม centroid จึงไม่ขยับ** ซึ่งเป็นเรื่องขั้นตอนที่ 3 ไม่ใช่ขั้นตอนที่ 2

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 ตารางอัปเดต centroid รอบที่ 2 (แถว C1) + ขั้นตอนที่ 3

## ข้อ 26 — [Lect 08] — คำนวณ centroid ของกลุ่ม C3

**โจทย์:** หลังจบรอบที่ 1 กลุ่ม C3 มีสมาชิก 2 จุด คือ A2(2,5) และ A7(1,2) จงคำนวณจุดศูนย์กลางใหม่ของกลุ่มนี้เป็นทศนิยม แล้วเลือกคู่พิกัดที่ถูกต้อง

**ตัวเลือก**
- ก) (1.5, 3.5)
- ข) (1.5, 2.5)
- ค) (2, 1.5)
- ง) (3, 7)

**เฉลย:** ก) (1.5, 3.5)

**วิธีทำ**
1. สมาชิก 2 จุด ($n = 2$): A2(2,5), A7(1,2)
2. มิติที่ 1: $(2 + 1) / 2 = 3 / 2 = 1.5$
3. มิติที่ 2: $(5 + 2) / 2 = 7 / 2 = 3.5$
4. ผลลัพธ์: $C3_{ใหม่} = (1.5, 3.5)$
5. เปรียบเทียบกับจุดศูนย์กลางเดิม C3(1,2) — ย้ายขึ้นตามมิติ y เพราะ A2 มีค่า y = 5 สูงกว่า A7 ที่มี y = 2
6. ชุด centroid ใหม่ที่ได้ทั้งหมด: $C1(2, 10) \cdot C2(6, 6) \cdot C3(1.5, 3.5)$

**ตัวเลือกหลอก:** ข้อ ง — (3, 7) คือ **ผลรวม** ของทั้งสองมิติก่อนหาร ($2+1=3$, $5+2=7$) ซึ่งเป็นกับดักเดียวกับข้อ 24; อีกคู่ที่มักโผล่คือสลับมิติ (2, 1.5) ซึ่งเกิดจากอ่านพิกัดของ A2 กับ A7 สลับกัน

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 ตารางอัปเดต centroid รอบที่ 2 (แถว C3)

## ข้อ 27 — [Lect 08] — เงื่อนไขการหยุด

**โจทย์:** ข้อความใดตรงกับเงื่อนไขการหยุดของอัลกอริทึม K-Means ตามที่สไลด์ระบุไว้มากที่สุด

**ตัวเลือก**
- ก) หยุดเมื่อรอบที่ 10 เสร็จสิ้น ไม่ว่าผลจะยังเปลี่ยนอยู่หรือไม่
- ข) หยุดเมื่อกลุ่มใดกลุ่มหนึ่งมีสมาชิกน้อยกว่า 2 จุด
- ค) วนกลับไปทำขั้นที่ 2 ต่อเนื่องจนกว่าค่าเฉลี่ยจะไม่เปลี่ยนแปลง หรือจนกว่าจะไม่มีสมาชิกข้ามกลุ่ม
- ง) หยุดเมื่อจำนวนกลุ่มที่ได้เป็น 3 กลุ่มตามที่กำหนด K ไว้

**เฉลย:** ค) วนกลับไปทำขั้นที่ 2 ต่อเนื่องจนกว่าค่าเฉลี่ยจะไม่เปลี่ยนแปลง หรือจนกว่าจะไม่มีสมาชิกข้ามกลุ่ม

**วิธีทำ**
1. ขั้นตอนที่ 4 ตามสไลด์คือ "กลับไปที่ขั้นที่สองจนกว่าค่าเฉลี่ยจะหยุดเปลี่ยน หรือจนกว่าจะไม่มีสมาชิกใดเปลี่ยนกลุ่ม" จึงมีเงื่อนไขหยุด **สองทาง** เป็นทางเลือก (OR) ไม่ใช่ต้องครบทั้งสองอย่าง
2. ทางที่ 1: ค่าเฉลี่ย (centroid) ของกลุ่มใดกลุ่มหนึ่งไม่เปลี่ยนแปลงเมื่อเทียบกับรอบก่อน
3. ทางที่ 2: เมื่อทำขั้นที่ 2 ซ้ำแล้ว **ไม่มีจุดข้อมูลใดเปลี่ยนกลุ่ม** แม้ว่า centroid จะยังขยับต่อก็ถือว่าหยุดได้
4. ตรวจกับตัวอย่างในสไลด์: กลุ่ม C1 มีสมาชิกจุดเดียว ค่าเฉลี่ยจึงไม่เปลี่ยนเลย ส่วนกลุ่ม C2 เปลี่ยนจาก (5,8) เป็น (6,6) และ C3 เปลี่ยนจาก (1,2) เป็น (1.5,3.5) ในรอบแรก แปลว่ายังไม่หยุดในรอบแรก ต้องวนรอบต่อไป
5. ข้อควรระวัง: สไลด์ไม่ได้กำหนดจำนวนรอบสูงสุดไว้ ฉะนั้นข้อ ก ซึ่งกำหนด "รอบที่ 10" จึงไม่มีที่มาจากสไลด์

**ตัวเลือกหลอก:** ข้อ ง — นักเรียนมักเข้าใจว่า "ได้ครบ K กลุ่มก็เสร็จ" เพราะในโจทย์นี้ได้ครบ 3 กลุ่มจริง แต่การได้ครบ K กลุ่มเป็นผลจากการทำขั้นที่ 2 ไม่ใช่เงื่อนไขหยุด เพราะ centroid ยังอาจขยับต่อจนกว่าจะลงที่ ข้อ ก ก็น่าเลือกเพราะดู "เป็นกฎทั่วไป" แต่สไลด์ไม่ได้ระบุตัวเลขรอบสูงสุด

## ข้อ 28 — [Lect 08] — จุดอ่อนของ K-Means

**โจทย์:** ข้อความใดเป็น **จุดอ่อน** ของ K-Means ตามที่สไลด์ระบุไว้มากที่สุด

**ตัวเลือก**
- ก) ใช้ได้เฉพาะข้อมูลที่หาค่าเฉลี่ยได้ ข้อมูลเชิงกลุ่มต้องเข้ารหัสเป็นตัวเลขก่อน เช่น ผอม 1 ปานกลาง 2 อ้วน 3
- ข) เข้าใจง่าย แก้ปัญหาได้ เพราะเป็นอัลกอริทึมพื้นฐาน
- ค) ทำงานเร็ว ความซับซ้อนเป็น O(tkn) โดย n คือจำนวนวัตถุ k คือจำนวนกลุ่ม และ t คือจำนวนรอบ
- ง) เป้าหมายของมันคือเพิ่มความคล้ายภายในกลุ่มให้มากที่สุด จึงตอบได้ตรงกับคำถามของงานจริง

**เฉลย:** ก) ใช้ได้เฉพาะข้อมูลที่หาค่าเฉลี่ยได้ ข้อมูลเชิงกลุ่มต้องเข้ารหัสเป็นตัวเลขก่อน เช่น ผอม 1 ปานกลาง 2 อ้วน 3

**วิธีทำ**
1. สไลด์แยกเป็นสองคอลัมน์ จุดแข็ง (Strength) กับจุดอ่อน (Weakness) ให้จำจำนวนให้ตรงกัน
2. **จุดแข็ง 3 ข้อตามสไลด์** คือ (1) เรียบง่าย ทำและ debug ได้ง่าย (2) เป้าหมายคือเป้าหมายเชิงคำนวณที่ optimize ความคล้ายภายในกลุ่ม (3) ทำงานได้ค่อนข้างมีประสิทธิภาพที่ O(tkn)
3. **จุดอ่อน 3 ข้อตามสไลด์** คือ (1) ใช้ได้เฉพาะที่ที่หาค่าเฉลี่ยได้ ข้อมูลเชิงกลุ่มต้องเข้ารหัสเป็นตัวเลขก่อน (2) มักหยุดที่ local optimum ค่าเริ่มต้นจึงสำคัญ (3) ต้องระบุ K ล่วงหน้า และจัดการข้อมูลผิดปกติได้ไม่ดี
4. จับคู่กับตัวเลือก: ข้อ ข, ค และ ง เป็นข้อความในคอลัมน์ **จุดแข็ง** ทั้งหมด ส่วนข้อ ก เป็นข้อความในคอลัมน์ **จุดอ่อน** ข้อ ก จึงถูกต้อง
5. เหตุผลเชิงกลไกที่ต้องอธิบายเพิ่ม: ขั้นตอนที่ 3 ของอัลกอริทึมคือ "คำนวณค่าเฉลี่ย" ซึ่งต้องการค่าที่บวกได้ ถ้าข้อมูลเป็นเชิงกลุ่ม เช่น ผอม/ปานกลาง/อ้วน การหาค่าเฉลี่ยของคำเหล่านี้ไม่มีความหมาย จึงต้องเข้ารหัสเป็นตัวเลขก่อนตามที่สไลด์กำหนด: ผอม 1 ปานกลาง 2 อ้วน 3
6. ข้อควรระวัง: การเข้ารหัสแบบนั้นทำให้ "ระยะทาง" มีความหมาย แต่ไม่ได้ทำให้ข้อมูลเชิงกลุ่มกลับมาเป็นเชิงเส้นได้ ตัวเลข 1 และ 2 ไม่ได้ "ห่างกัน" จริงในความหมายต้นฉบับ

**ตัวเลือกหลอก:** ข้อ ค — นักเรียนมักเลือกเพราะเป็นข้อความที่ดู "ทางเทคนิค" และจำได้จากสไลด์ว่ามีความซับซ้อน O(tkn) แต่จำไม่ได้ว่าอยู่คอลัมน์ไหน — O(tkn) เป็น **จุดแข็ง** เพราะสไลด์บอกว่าทำงานได้ค่อนข้างมีประสิทธิภาพ (และเพราะ k กับ t มักเล็กกว่า n มาก); ข้อ ข และ ง ก็เป็นจุดแข็งเช่นกัน ข้อนี้จึงเป็นข้อที่ต้องแยก "คอลัมน์" ไม่ใช่ข้อที่ต้องคำนวณ

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 สไลด์ตาราง Strength / Weakness (พร้อมตัวอย่างการเข้ารหัส ผอม 1 ปานกลาง 2 อ้วน 3)

## ข้อ 29 — [Lect 08] — เปรียบเทียบ Manhattan กับ Euclidean

**โจทย์:** จุดข้อมูล A3(8,4) มีระยะทางจากจุดศูนย์กลาง C2(5,8) เท่ากับ 7 เมื่อใช้ Manhattan จงคำนวณระยะทาง Euclidean ของคู่เดียวกันนี้ แล้วเลือกข้อความที่ถูกต้องที่สุด

**ตัวเลือก**
- ก) 7
- ข) 25
- ค) √25 = 5
- ง) 49

**เฉลย:** ค) √25 = 5

**วิธีทำ**
1. ตรวจ Manhattan ก่อนเพื่อยืนยันว่าใช้คู่พิกัดถูก:
   - $|8 - 5| = 3$
   - $|4 - 8| = 4$
   - รวม $3 + 4 = 7$ ตรงกับค่าในตารางรอบที่ 1 ✓
2. คำนวณ Euclidean ตามสูตร $d(A,Y) = \sqrt{\sum (x_i - y_i)^2}$
   - $(8 - 5)^2 = 3^2 = 9$
   - $(4 - 8)^2 = (-4)^2 = 16$
   - รวม $9 + 16 = 25$
   - ถอดรากที่สอง: $\sqrt{25} = 5$
3. ผลลัพธ์ Euclidean คือ **5** ซึ่งต่างจาก Manhattan ที่ได้ 7 แม้จะเป็นคู่พิกัดเดียวกัน
4. ข้อสรุปที่ต้องเขียน: Manhattan บวกค่าสัมบูรณ์; Euclidean ยกกำลังสองก่อนบวก **แล้วถอดรากที่สอง** — ให้คำตอบต่างกันเมื่อนำไปเทียบกัน
5. การเปรียบเทียบ: Manhattan (7) > Euclidean (5) ในกรณีนี้ เพราะรากที่สองดึงค่ากลับเข้าหา 0 เสมอ

**ตัวเลือกหลอก:**
- ข้อ ก (7) — นำค่า Manhattan มาตอบทั้งที่โจทย์ถาม Euclidean เป็นกับดักที่พบบ่อยที่สุด เพราะ 7 คือตัวเลขที่ปรากฏในตารางรอบที่ 1 ของสไลด์ตรงๆ
- ข้อ ข (25) — คำนวณถูกตลอดแต่ **ลืมถอดรากที่สอง** 25 คือผลรวมกำลังสอง ไม่ใช่ระยะทาง
- ข้อ ง (49) — เกิดจากยกกำลังสองของ Manhattan คือ $7^2 = 49$ โดยไม่ได้แตกเป็นรายมิติและไม่ได้ถอดราก

> **หมายเหตุสำหรับผู้สอน:** ข้อนี้เลือกใช้คู่ A3 กับ C2 เพราะผลรวมกำลังสองเป็น 25 ซึ่งถอดรากได้พอดีเป็นจำนวนเต็ม ไม่ต้องปัดเศษ ต่างจากคู่ A1 กับ C2 ในข้อ 22 ที่ Manhattan ได้ 5 แต่ Euclidean ได้ √13 (ไม่ลงตัว)

**สถานะการตรวจสอบ:** FROM-SLIDE

**อ้างอิงสไลด์:** LECT 08 สไลด์สูตร Euclidean ($d(A,Y) = \sqrt{\sum (x_i - y_i)^2}$) + ตารางรอบที่ 1 (แถว A3)

> **คำเตือนเรื่องสไลด์ 15:** สไลด์ตัวอย่าง Euclidean ที่พิมพ์ไว้มีเลขคำนวณไม่ตรงกับเวกเตอร์ที่พิมพ์คู่กัน **ห้ามใช้ตัวเลขจากสไลด์หน้านั้นเป็นเฉลย** ให้แทนค่าจากพิกัดจริงทุกครั้ง ข้อนี้จึงใช้เฉพาะสูตร Euclidean ที่ถูกต้องจากสไลด์ ร่วมกับพิกัดจากตารางข้อมูล

## ข้อ 30 — [Lect 08] — Manhattan กับ WCSS / Inertia

**โจทย์:** ในการทำ K-Means ด้วยมือในข้อสอบใช้ระยะทางแบบ Manhattan แต่ค่า WCSS / Inertia ในทางทฤษฎีใช้ระยะทางอีกแบบหนึ่ง ข้อความใดอธิบายความต่างนี้ได้ถูกต้องที่สุด

**ตัวเลือก**
- ก) WCSS / Inertia ใช้ Manhattan เช่นเดียวกัน เพียงแต่รวมค่าจากทุกจุดในกลุ่มแล้วหารด้วยจำนวนกลุ่ม
- ข) WCSS / Inertia ใช้ Euclidean แบบยกกำลังสอง (squared Euclidean) ซึ่งทำให้ค่าเป็นบวกเสมอและหาอนุพันธ์ได้ง่าย จึงเป็นเป้าหมายเชิงคำนวณที่ใช้หาค่าเฉลี่ยที่ดีที่สุดได้
- ค) WCSS / Inertia ใช้ Chebyshev เพราะหาค่าต่ำสุดได้เร็วกว่า
- ง) ทั้งสองแบบให้คำตอบเท่ากันเสมอ เพียงแต่เขียนสูตรต่างกัน

**เฉลย:** ข) WCSS / Inertia ใช้ Euclidean แบบยกกำลังสอง (squared Euclidean) ซึ่งทำให้ค่าเป็นบวกเสมอและหาอนุพันธ์ได้ง่าย จึงเป็นเป้าหมายเชิงคำนวณที่ใช้หาค่าเฉลี่ยที่ดีที่สุดได้

**วิธีทำ**
1. ตรวจจากตัวเลขของสไลด์ว่าสองแบบให้ผลต่างกันจริง โดยใช้คู่ A1(2,10) กับ C2(5,8)
   - Manhattan: $|2-5| + |10-8| = 3 + 2 = 5$
   - Squared Euclidean: $(2-5)^2 + (10-8)^2 = (-3)^2 + 2^2 = 9 + 4 = 13$
   - ค่าต่างกัน (5 vs 13) ดังนั้นข้อ ง ที่ว่า "เท่ากันเสมอ" ผิดทันที
2. เหตุผลเชิงหลักการว่าทำไม WCSS/Inertia ต้องใช้ยกกำลังสอง
   - ค่ายกกำลังสองไม่เคยติดลบ จึงไม่มีปัญหาการ "หักล้างกัน" ของค่าที่ติดลบ
   - ฟังก์ชันระยะที่ยกกำลังสองมีอนุพันธ์ที่ราบรื่น (smooth) จึงหาค่าต่ำสุดด้วยวิธีเชิงคำนวณได้ง่าย
   - ค่าเฉลี่ย (mean) คือจุดที่ทำให้ **การกระจายแบบยกกำลังสอง** มีค่าน้อยที่สุด ดังนั้นขั้นตอนที่ 3 ("คำนวณค่าเฉลี่ย") จึงสอดคล้องกับการลด WCSS พอดี
3. ข้อควรระวังที่ต้องเขียนในกระดาษ: ค่าเฉลี่ยไม่ได้ทำให้การกระจายแบบ **Manhattan** มีค่าน้อยที่สุด — ค่าที่ทำให้ L1 มีค่าน้อยที่สุดคือ **ค่ามัธยฐาน (median)** ดังนั้นตารางที่คิดด้วยมือด้วย Manhattan ไม่ได้ถูกรับประกันตามหลักว่าจะลดลงทุกรอบเท่ากับตารางที่ใช้ยกกำลังสอง
4. ข้อสรุปที่ต้องเขียน: เป็น **สองงานคนละอย่าง** — Manhattan เลือกเพราะตรวจด้วยมือได้ (เลขจำนวนเต็ม บวกล้วน) ส่วน squared Euclidean ใช้เป็นเป้าหมายเชิงคำนวณของ WCSS/Inertia
5. การนำไปใช้ต่อ: WCSS / Inertia คือค่าที่ใช้เปรียบเทียบว่า k ต่าง ๆ ให้ผลดีแค่ไหน (ยิ่งต่ำยิ่งดี) ซึ่งเชื่อมโยงกับจุดอ่อนที่สไลด์ระบุว่าต้องลองหลายค่า k

**ตัวเลือกหลอก:** ข้อ ก — เป็นการ "ต่อเนื่อง" มากที่สุด เพราะนักเรียนที่ทำ K-Means ด้วยมือทั้งหมดจะเชื่อว่าทุกอย่างใช้ Manhattan ตลอด แต่ข้อนี้ถูกตัดกันด้วยการแทนค่าจริงในขั้นที่ 1 (5 ≠ 13); ข้อ ง ถูกตัดกันด้วยตัวเลขเดียวกัน ส่วนข้อ ค เป็นมิเตอร์ที่ไม่ได้ปรากฏในสไลด์เลย
