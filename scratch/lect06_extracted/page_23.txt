### 🎯 Main Topic:  
**1. Supervised Learning**

> *“Learn to label”* — This phrase encapsulates the core objective of supervised learning: training a model to assign correct labels (categories or values) to input data based on known examples.

---

### 🔑 Key Concepts & Takeaways:

#### 1. **The Resultant Model is Called “Classifier”**
- In supervised learning, especially for classification tasks, the output of the training process is a **classifier**.
- A classifier learns decision boundaries or rules that map input features to discrete class labels (e.g., apple vs. lime).

#### 2. **Requires Large Amount of Training Data**
- Supervised models, particularly classifiers, depend heavily on **large volumes of labeled training data**.
- More diverse and representative training data generally leads to better generalization and accuracy in real-world predictions.

#### 3. **Prediction Can Be Wrong**
- Even with robust training, **predictions are not guaranteed to be correct**.
- Errors can arise due to noisy data, insufficient training samples, overfitting, or misaligned feature representations.
- This underscores the importance of evaluating model performance using metrics like accuracy, precision, recall, etc.

#### 4. **Feature Engineering is the Key to Success**
- **Feature engineering** — the process of selecting, transforming, and creating relevant input variables (features) from raw data — is critical to building effective supervised learning models.
- Well-engineered features help the model distinguish between classes more effectively, leading to improved predictive power.
