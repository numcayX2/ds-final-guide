Example: K-Mean Clustering

**Distance Calculation (Manhattan):**
*   Formula: $Distance_{manhattan}(A, Y) = |x1 - y1| + |x2 - y2|$
*   Variables: Case ข้อมูล (V1, V2); A ($x1, x2$), Y ($y1, y2$)

**Step-by-Step Distance Examples:**
*   **point mean1:**
    *   point ($x1, x2$): (2, 5)
    *   mean1 ($y1, y2$): (2, 10)
    *   distance(point, mean1) = $|x1 - y1| + |x2 - y2|$
    *   $= |2 - 2| + |5 - 10|$
    *   $= 0 + 5 = 5$
*   **point mean2:**
    *   point ($x1, x2$): (2, 5)
    *   mean2 ($y1, y2$): (5, 8)
    *   distance(point, mean2) = $|x1 - y1| + |x2 - y2|$
    *   $= |2 - 5| + |5 - 8|$
    *   $= 3 + 3 = 6$
*   **point mean3:**
    *   point ($x1, x2$): (2, 5)
    *   mean3 ($y1, y2$): (1, 2)
    *   distance(point, mean3) = $|x1 - y1| + |x2 - y2|$
    *   $= |2 - 1| + |5 - 2|$
    *   $= 1 + 3 = 4$
