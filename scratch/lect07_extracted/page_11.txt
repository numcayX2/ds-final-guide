Gini Impurity Measures Class Mixing

**Gini(t) = 1 - Σ pₖ²**
- **pₖ** = สัดส่วนของแต่ละ Class ใน Node
- **Gini = 0.278** (calculated as 1 - (5/6)² - (1/6)²)

**Interpretation:**
- **0 = Pure**
- **ค่าต่ำ = Class Majority ชัดเจน**
- **ค่าสูงขึ้น = Class ผสมมากขึ้น**

**Takeaway:** Gini Impurity เปลี่ยนระดับการผสมของ Class ให้เป็นหลักฐานที่ Algorithm เปรียบเทียบได้
